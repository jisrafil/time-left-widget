# Widgets v1 — frozen for sold templates

Copied on 2026-10-30 from the main widgets (commit 222853f).

Notion templates sold by The Crafty Capricorn link to the widgets in this folder,
for example `https://jisrafil.github.io/time-left-widget/v1/progress/?theme=custom&...`.

**Do not change anything in `v1/`.** Buyers' copies of the templates point here, so
any change in this folder changes every buyer's widget at once.

- Improve the widgets in the main folders (`/progress/`, `/pomodoro/` and so on) as usual.
  Those are not used by sold templates.
- When an improvement is ready for templates, copy the widgets into a new folder
  (`v2/`) and point new template releases at it. Older buyers stay on `v1/`.
- Only a real fix for something broken (with Johnny's OK) may go into `v1/`, and it
  should be noted below.

Widgets in v1: analog-clock, clock, countdown, flip-clock, greeting, pomodoro,
progress, quote, reading-soundtrack, plus `assets/widget.js` and `assets/widget.css`.
